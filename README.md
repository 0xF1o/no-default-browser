# Browser Picker - Android App

This Android application allows you to select which browser to use when opening web links from other apps. Instead of being forced to use your default browser, you can choose a different browser for each link.

## Features

- **Browser Selection**: Choose from all installed browsers when opening web links
- **No Default Browser Required**: Use any browser you want for each individual link
- **Easy Integration**: Works with any app that opens web URLs
- **No Installation Required**: Works with existing browsers on your device

## How It Works

1. When you tap on a URL in another app (like email, messaging, etc.), this app will appear as an option
2. You'll see a list of all browsers installed on your device
3. Select the browser you want to use for that particular link
4. The selected browser will open and load the URL

## Usage

1. Install this app on your Android device
2. When you open a URL from another app, select "Pick Browser" from the options
3. Choose your preferred browser from the list that appears

## Requirements

- Android 7.0 (API level 24) or higher
- At least one web browser installed on your device

## Building

To build the APK:

```bash
./build.sh
```

The built APKs will be available in the `apk/` directory.
